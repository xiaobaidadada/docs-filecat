# Welcome to FileCat

FileCat is a **self-hosted file manager and server operations tool**. Run a single process and manage files, drive a terminal, connect to other servers, and use AI for everyday operations — all from the browser.

## What it solves

Managing a server usually means juggling several tools at once:

- an SFTP client to move files
- an SSH terminal to run commands
- a panel to watch CPU and processes
- yet another tool for tunneling

FileCat folds all of that into one interface, and adds permission isolation on top — so each member of a team only sees the directories and commands they are allowed to use.

## Feature overview

**Main features** (each has its own page)

- File management, online editing, terminal
- AI assistant (including DingTalk / Lark / QQ bots)
- Mounts (local, WebDAV, SFTP, SMB, S3, Baidu Netdisk, TCP proxy)
- File services (expose WebDAV, SMB, SFTP, FTP)
- Tunneling, virtual network, file sync
- Workflow

**Other features** (brief notes in [Other Features](./功能特性/其它.md))

- System monitor, process manager, Docker, systemd, disks
- Users and permissions, audit log, DDNS, certificates, firewall
- SSH manager, RDP, browser proxy, HTTP proxy
- Scheduled tasks, notifications, video transcoding, text diff

## Three main areas

After deployment, open `http://your-ip:5567`:

- **Files** — the default page, for browsing server directories
- **Settings** — environment, system, AI, mounts, tunneling, and everything else
- **Terminal** — open a shell session
