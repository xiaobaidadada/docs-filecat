# Virtual Network

Assign virtual IPs to several machines so they behave like a single LAN. Useful for home and office setups without public IPs.

## Steps

**1. Prepare a machine with a public IP as the server**

Install and start FileCat on it, open **Settings → Virtual Network → Server**, and note the listening port and key.

**2. Configure the other machines as clients**

On each machine that should join:

1. Open **Settings → Virtual Network → Client**
2. Enter the server's public IP, port and key
3. **Choose a virtual IP yourself** (the client picks its own; the server does not assign one)
4. Start the client

**3. Verify connectivity**

The machines can now reach each other over their virtual IPs.

> To test a client against a server running on the **same machine**, set the server address to `localhost`.

## Windows requires administrator rights

Creating a virtual network adapter on Windows **requires elevation**. Without running FileCat as administrator, the virtual IP cannot be created.

## Windows treats it as a public network

The adapter is classified as a public network by default, which means **ping fails** (normal traffic still works).

Switch it to private:

```bash
Set-NetConnectionProfile -InterfaceAlias "filecat" -NetworkCategory Private
```

Verify:

```bash
Get-NetConnectionProfile
```

Check that the `filecat` entry shows `NetworkCategory` as `Private`.

## Letting the server reach clients

The server can also **run a client connecting to itself**.

That way, even when a client sits behind NAT, the server can initiate requests to it — removing the "only the client can connect outward" limitation.

## Reaching other hosts on a client's LAN (TCP proxy)

The virtual network only connects machines that have joined it.

To reach **other devices** on a client's internal network (a printer or NAS next to it):

1. Configure a **TCP proxy** on that client
2. Access the other hosts' IPs through the relay

## P2P mode has been removed

Earlier versions attempted UDP hole-punching for direct P2P, but domestic ISPs restrict UDP heavily (unusable on many Mobile networks), so the feature was removed and is no longer maintained.

All traffic now relays through the server, so pick one with adequate bandwidth and stability.
