# Other Features

Clear-cut capabilities with simple usage. One line each; detailed guides will be added over time.

## Server management

| Feature | Description |
| --- | --- |
| **System monitor** | Live CPU, memory, disk and network usage; collection is implemented in C++ and barely uses any resources |
| **Process manager** | List all processes and kill them; lighter than comparable panels |
| **Docker** | List containers, view logs, start and stop them |
| **systemd** | Manage systemctl services — start/stop, status and logs; few panels offer this |
| **Disks** | Inspect mounts and configure mount entries |

## Security and networking

| Feature | Description |
| --- | --- |
| **Users and permissions** | Multi-user, controlling which directories and operations each account can use |
| **Audit log** | Records file operations, logins and command execution |
| **DDNS** | Dynamic DNS with support for Alibaba Cloud, Tencent Cloud, Cloudflare, DNSPod, GoDaddy, Namecheap, NameSilo, Vercel, DynDNS, TokenDNS and HTTP DDNS — over a dozen providers |
| **Certificates** | Request and renew SSL certificates for HTTPS |
| **Firewall** | Manage the server firewall rules |
| **Port scan** | Scan open ports on a given host |

## Remote access

| Feature | Description |
| --- | --- |
| **SSH manager** | Store credentials for many remote Linux servers; one click logs in and lets you manage their files and run commands as if local. Near-native file operations, code editing supported, preview not; the terminal is the remote machine's own shell rather than pty-shell |
| **RDP** | Remote-control a Windows desktop in the browser |
| **Browser proxy** | Opens an extra HTTP port that serves an internal web UI (a router admin page, for example) directly in the browser |
| **HTTP proxy** | A small built-in Postman: form-based file uploads and background downloads that save straight onto the server |
| **Bookmarks** | Save frequently visited web addresses with multi-level categories |
| **Quick commands** | Save common commands and run them with one click |
| **RTSP player** | Requires ffmpeg; enter an rtsp URL to play a camera feed online |
| **Wake-on-LAN** | Send a WOL magic packet to a MAC address; the target just needs to be plugged in |

## Content and media

| Feature | Description |
| --- | --- |
| **Video playback** | Play video online in common formats |
| **Video transcoding** | Convert formats using a system-installed ffmpeg (ffmpeg is large and must be installed separately) |
| **Image preview** | Grid preview of images; right-click to disable previews when the network is slow |
| **Text diff** | Compare two files |

## Automation

| Feature | Description |
| --- | --- |
| **Workflow** | An embedded workflow engine with GitHub Actions-style syntax, able to replace Jenkins for builds |
| **Scheduled tasks** | Run commands or jobs on a cron schedule |
| **HTTP proxy download** | Download remote HTTP resources in the background without tying up the browser |
| **Static site proxy** | Serve any directory as a static site, with optional custom login |
| **SMS and email notifications** | Notification channels for task results and alerts |

## Interface and experience

| Feature | Description |
| --- | --- |
| **Multi-language** | Chinese and English UI |
| **Dark theme** | Follow the system or switch manually |
| **Sorting and favorites** | Sort files by name, size or time |
| **Path jump** | Type a target path into the breadcrumb to jump quickly |
