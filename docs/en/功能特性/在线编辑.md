# Online Editing

## Editing a single file

**Double-click** a text file in the list to open the editor. Press `Ctrl+S` to save; it writes straight back to the server.

Built on Ace, the editor picks syntax highlighting from the file extension. If it guesses wrong (an extension-less config file, say), pick the language manually in the bottom-right corner.

## Studio mode: edit a whole project

Double-clicking one file at a time is slow when you need to change several:

1. **Right-click the target folder** in the list
2. Choose **Open in Studio**
3. A file tree appears on the left; click files to open them on the right
4. Multiple files stay open, switchable via the tabs on top

Close to a VSCode experience — good for temporary development or batch config edits on a Linux server.

## Creating an Excalidraw whiteboard

Two ways:

**Option 1**: When creating a file, choose the Excalidraw type.

**Option 2**: Create any file and give it the `.draw` extension, then double-click it.

The result is saved in Excalidraw's JSON format, and double-clicking the `.draw` file again reopens it for further editing.

> Note: `.draw` files only open properly inside FileCat. Other editors show raw JSON.

## Editing Markdown

Double-clicking a `.md` file opens the **rendered** view by default — the formatted layout.

To change content:

1. Open the `.md` file
2. Switch to the **source** view (or edit directly)
3. Save

You can switch between views at any time and preview changes immediately.

## Editing images

For png / jpg images, right-click → **Edit**:

1. filerobot-image-editor opens
2. Crop, rotate or annotate
3. Saving **overwrites the original file**

> Overwriting is irreversible. Copy important images before editing.

## Comparing two files

For reviewing config changes or code differences:

1. Right-click the first file
2. Choose **Compare**
3. Select the second file
4. Differences appear side by side

Added and removed lines are colour-coded, which makes comparing two configs straightforward.
