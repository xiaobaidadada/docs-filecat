# File Management

## Configure a root directory

Nothing shows up until at least one root directory exists.

1. Open **Settings → Environment**
2. Find the **Root Directories** field and enter an absolute server path, such as `/data` or `D:\data`
3. Save and return to the Files page — the directory appears immediately

You can add several roots; a switcher appears in the top-right corner. Assigning different roots to different users gives you directory isolation.

## Uploading large files (resumable)

Plain HTTP upload is the default. For large files or unstable networks, switch to chunked resumable upload:

1. Open **Settings → Environment**
2. Find **upload concurrency limit**
3. Configure it **per directory**

The setting is per-directory because directories may live on different disks: mechanical drives slow each other down at high concurrency, while SSDs handle more.

With chunked upload enabled, transfer goes over WebSocket. If interrupted, re-uploading the same file resumes from the break instead of starting over.

## Compress and extract

**Compress**: select multiple files → click the compress button → choose tar / zip / gz.

**Extract**: right-click an archive → extract. Extraction supports more formats than compression, including **rar**.

## Opening huge logs

A normal editor freezes on a several-hundred-megabyte file. Use log mode:

1. Right-click the target file
2. Choose **Open as log**
3. Scroll through the whole file; new content is **appended live** at the end

> UTF-8 only. Non-UTF-8 files show garbled text and must be converted on the server first.

## Setting up the recycle bin

Deletion is permanent by default. To enable the recycle bin:

1. Open **Settings → System**
2. Find the **Recycle bin** setting
3. Use this format:

```
[parent directory of deleted file] recycle bin directory [; ...]
```

For example, to move files deleted from `/data` into `/data/.recycle`:

```
/data /data/.recycle
```

Separate multiple rules with semicolons to give each directory its own bin.

> This only applies to deletions made in the UI. Files removed with `rm` in a terminal do not go to the recycle bin.

## Protecting critical directories

To prevent accidentally deleting something like `/etc`:

1. Open **Settings → Environment**
2. Find **Protected paths**
3. Enter directories that must not be deleted, separated by commas

Deletion is rejected inside protected paths. There are two kinds: **system protected paths** apply to everyone, **user protected paths** apply only to regular users.

## Editing a whole project with Studio

To change several files in one project:

1. **Right-click a folder** (not a file) in the list
2. Choose **Open in Studio**
3. A file tree appears on the left; click files to edit them on the right

Much faster than double-clicking each file — handy for editing a batch of configs or inspecting project layout.

## Three ways to change directory

| Method | Notes |
| --- | --- |
| Breadcrumb | Click any level to jump straight there |
| Breadcrumb input | Click the end of the breadcrumb to type a full path and press Enter |
| Relative path | Resolved against the current directory; cannot escape the root |

## Searching

Currently searches by file name **within the current directory**. The list filters as you type; file contents are not searched.
