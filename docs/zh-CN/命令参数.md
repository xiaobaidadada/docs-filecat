# 命令参数

FileCat 支持通过命令行参数和环境变量两种方式配置启动行为。参数优先级高于环境变量。

## 基本用法

```bash
# npm 全局安装后
filecat --port 5567 --base_folder /data/filecat

# 源码运行
node src/main/main.js --port 5567
```

## 常用参数

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--port` | Web 服务监听端口 | `5567` |
| `--hostname` | 监听地址 | `0.0.0.0` |
| `--base_folder` | 数据根目录，存数据库、日志、缓存等 | 见下文 |
| `--user_name` | 初始化管理员账号 | `admin` |
| `--password` | 初始化管理员密码 | 随机生成 |
| `--lang` | 默认界面语言，可选 `zh` / `en` / `sys` | `sys` |
| `--https_port` | HTTPS 监听端口 | 未启用 |
| `--ssl_key` | SSL 证书私钥路径 | — |
| `--ssl_cert` | SSL 证书路径 | — |
| `--watch` | 监听文件变化自动重载（开发用） | 关闭 |

> `--lang sys` 表示跟随浏览器语言。

## 数据目录

`--base_folder` 决定了所有持久化数据的位置，包括：

- `data.json` 等数据库文件
- 上传临时文件
- 日志
- 回收站（若配置在默认位置）

如果从源码运行且未指定，通常落在项目下的 `filecat-data` 目录。

> 迁移服务器时，把整个 `base_folder` 拷走即可保留全部数据。

## 环境变量

每个命令行参数都有对应的环境变量形式，前缀为 `FILECAT_`，大写并以下划线连接。

例如：

```bash
# 等价于 --port 8080
export FILECAT_PORT=8080
```

适合在 Docker、systemd 等场景下配置，避免改启动脚本。

## 安装管理员账号

首次启动时可以用参数指定管理员账号密码：

```bash
filecat --user_name admin --password yourpassword
```

如果不指定，密码会随机生成并打印在控制台，请及时查看并修改。

> 账号密码只在**首次初始化**时生效，之后修改需要通过界面或数据库进行。

## 开发相关

| 参数 | 说明 |
| --- | --- |
| `--watch` | 监听源码变化并自动重载，仅开发时使用 |

生产环境不要开启，会增加不必要的文件监听开销。

## 查看当前生效配置

启动后控制台会打印实际的监听地址与数据目录。若发现端口冲突，优先检查是否已有 FileCat 实例在运行。
