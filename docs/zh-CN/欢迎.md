# 欢迎使用 FileCat

FileCat 是一个**自托管的文件管理与服务器运维工具**。部署一个进程，就能在浏览器里管理文件、操作终端、连接其它服务器、调用 AI 完成日常运维。

## 它解决什么问题

传统做法下，管理一台服务器往往要同时打开：

- 一个 SFTP 客户端传文件
- 一个 SSH 终端敲命令
- 一个面板看 CPU 和进程
- 一个工具做内网穿透

FileCat 把这些收进同一个界面，并且额外提供了权限隔离 —— 让团队里不同的人只能看到属于自己的目录、执行被允许的命令。

## 功能全景

**主要功能**（有专门文档）

- 文件管理、在线编辑、终端
- AI 助手（含钉钉 / 飞书 / QQ 机器人）
- 网盘挂载（本地、WebDAV、SFTP、SMB、S3、百度网盘、TCP 代理）
- 文件服务（对外提供 WebDAV、SMB、SFTP、FTP）
- 内网穿透、虚拟网络、文件同步
- Workflow 工作流

**其它功能**（简要说明见 [其它功能](./功能特性/其它.md)）

- 系统监控、进程管理、Docker、systemd、磁盘管理
- 用户权限、操作日志、DDNS、证书、防火墙
- SSH 管理、RDP、浏览器代理、HTTP 代理
- 计划任务、通知、视频转码、文本对比

## 三个常用入口

部署完成后，浏览器打开 `http://你的IP:5567`：

- **文件** —— 默认落地页，管理服务器目录
- **设置** —— 环境、系统、AI、挂载、穿透等全部配置
- **终端** —— 打开一个 shell 会话
