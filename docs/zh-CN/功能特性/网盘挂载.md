# 网盘挂载

把远端存储挂进 FileCat，像本地目录一样浏览。

## 先理解两个概念

配置分成两半，搞不清这两个就配不对：

- **凭据（Credential）** —— 怎么连：地址、端口、账号密码
- **挂载（Mount）** —— 挂到哪：共享名、桶名、起始目录

一份凭据可以配多个挂载。比如同一个 NAS 上有三个共享目录，只需配一份凭据，再加三条挂载。

顺序是：**先建凭据 → 再建挂载**。

## 挂载 SMB（Windows 共享 / 群晖 / NAS）

**第一步：建凭据**

1. 打开 **设置 → 挂载 → 凭据**
2. 类型选 `SMB`
3. 填写主机地址，例如 `192.168.x.x` 或 `nas.local`
4. 填写用户名、密码
5. 保存

**第二步：建挂载**

1. 切到 **挂载** 标签
2. 类型选 `SMB`，选择刚建的凭据
3. 「位置」填**共享名**，例如 `share`
4. 保存，回到文件页就能看到目录

> 「位置」填的是共享名，不是路径。要进子目录写成 `share/docs`。
> **不要**写 `\\192.168.x.x\share` 这种 Windows 路径，也不要在开头加 `/`。

## 挂载 S3 对象存储

**凭据**需要填：EndPoint（如 `https://oss-cn-hangzhou.aliyuncs.com`）、AccessKey、SecretKey、Region。

**挂载**的「位置」填**桶名**，例如 `my-bucket`。要限制到某个前缀写成 `my-bucket/photos`。

兼容 MinIO、阿里云 OSS、七牛等 S3 协议存储。如果服务商要求 path-style 访问，在凭据里打开对应开关。

## 挂载 SFTP

**凭据**：主机、端口（默认 22）、用户名，认证方式选密码或私钥。

**挂载**的「位置」填远端起始目录，填 `/` 表示从根开始。

适合连接另一台 Linux 服务器。如果对端也是 FileCat，可以在那边开「文件服务 → SFTP」，这边用 SFTP 挂载对接。

## 挂载 WebDAV

**凭据**：完整 URL（如 `https://dav.example.com/remote.php/dav/files/user`）、用户名、密码。

**挂载**的「位置」填起始目录，一般填 `/`。

Nextcloud、坚果云等都用这个协议。

## 挂载百度网盘

在凭据里完成 OAuth 授权，FileCat 会跳转到百度登录页，授权后自动回填 token。

授权有效期有限，过期后需要重新授权。如果提示鉴权失败，先检查凭据页面上的 token 是否已失效。

## 挂载本地其它目录

用于把服务器上不在根目录里的路径也暴露出来。

**挂载**类型选「本地目录」，「位置」留空 —— 源目录由凭据绑定的账号决定，在凭据里指定实际路径。

## 挂载后目录是空的？

按这个顺序排查：

1. **「位置」字段填错** —— 最常见。SMB 填共享名（不带反斜杠、不带开头斜杠），S3 填桶名
2. **网络不通** —— 在服务器上用 `telnet 主机 端口` 测试连通性
3. **账号权限不足** —— 换一个有读写权限的账号试
4. **改过配置但没生效** —— 正常情况下改配置会自动重建连接，如果还不行，重新保存一次挂载

## 修改配置后需要重连吗

不需要。

FileCat 会按「挂载 + 配置指纹」缓存驱动实例。改了凭据或挂载配置后，指纹变化，缓存自动失效并重建连接。

## 挂载和文件服务的区别

| | 网盘挂载 | 文件服务 |
| --- | --- | --- |
| 方向 | 把外部存储**拉进来** | 把本地目录**推出去** |
| 谁连谁 | FileCat 去连别人 | 别人来连 FileCat |
| 配置位置 | 设置 → 挂载 | 设置 → 文件服务 |

两台 FileCat 之间互相访问，两边都可以：一边配挂载，或一边开文件服务。
