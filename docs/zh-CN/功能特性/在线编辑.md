# 在线编辑

## 编辑单个文件

在文件列表里**双击**文本文件即可打开编辑器，修改后按 `Ctrl+S` 保存，直接写回服务器。

编辑器基于 Ace，会根据文件后缀自动切换语法高亮。如果后缀识别错了（比如无后缀的配置文件），在编辑器右下角手动选语言。

## Studio 模式：编辑整个项目

改一个项目的多个文件时，逐个双击太慢：

1. 在文件列表里**右键目标文件夹**
2. 选择「Studio 打开」
3. 左侧出现文件树，点击文件在右侧编辑区打开
4. 可以同时打开多个文件，通过顶部标签切换

适合在 Linux 服务器上临时开发或批量改配置，体验接近 VSCode。

## 新建 Excalidraw 白板

两种方式：

**方式一**：新建文件时，在文件类型里选择 Excalidraw。

**方式二**：新建一个文件，把后缀写成 `.draw`，双击即可打开绘图界面。

绘制结果保存为 Excalidraw 的 JSON 格式，之后再次双击 `.draw` 文件可以继续编辑。

> 注意：`.draw` 文件只能用 FileCat 打开，其它编辑器看到的是原始 JSON。

## 编辑 Markdown

`.md` 文件双击进来默认是**渲染后的效果**，看到的是排版好的样子。

要改内容：

1. 打开 `.md` 文件
2. 切换到「源码」视图（或直接编辑）
3. 修改后保存

两个视图之间可以随时切换，改完即时预览。

## 编辑图片

对 png / jpg 图片，右键 → 「编辑」：

1. 打开 filerobot-image-editor
2. 可以裁剪、旋转、加标注
3. 保存后**直接覆盖原文件**

> 覆盖是不可逆的，重要图片建议先复制一份再编辑。

## 对比两个文件

用于查看配置改动、代码差异：

1. 右键第一个文件
2. 选择「对比」
3. 再选择第二个文件
4. 差异会左右并排显示

新增和删除的行有颜色区分，适合比对两份配置的异同。
