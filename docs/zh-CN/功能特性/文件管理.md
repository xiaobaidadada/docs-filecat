# 文件管理

## 配置根目录

首次使用必须先在 **设置 → 环境 → 根目录** 中添加至少一个目录，否则文件页是空的。

1. 打开 **设置 → 环境**
2. 找到「根目录」一栏，填写服务器上的绝对路径，例如 `/data` 或 `D:\data`
3. 保存后回到文件页，目录立即出现

可以添加多个根目录，右上角会出现切换入口。给不同用户分配不同根目录，就能实现目录隔离。

## 上传大文件（断点续传）

默认走普通 HTTP 上传。文件较大或网络不稳时，改用分片断点上传：

1. 打开 **设置 → 环境**
2. 找到「上传并发限制」
3. **按目录**分别配置并发数

按目录配置的原因是不同目录可能挂在不同硬盘上：机械硬盘并发开大会互相拖慢，SSD 可以开高一些。

启用分片上传后，传输走 WebSocket；中断后重新上传同一文件会从断点继续，不会从头开始。

## 压缩与解压

**压缩**：多选文件 → 点击工具栏的压缩按钮 → 选择格式（tar / zip / gz）。

**解压**：右键压缩包 → 选择解压。支持的格式比压缩多，额外支持 **rar**。

## 查看超大日志

普通编辑器打开几百 MB 的文件会卡死。用日志模式：

1. 右键目标文件
2. 选择「以日志方式打开」
3. 可以滚动浏览全文，内容有新增时会**实时追加**到末尾

> 仅支持 UTF-8 编码。非 UTF-8 文件会显示乱码，需要先在服务器上转码。

## 配置回收站

默认删除是直接删除。要启用回收站：

1. 打开 **设置 → 系统**
2. 找到「回收站」配置项
3. 按这个格式填写：

```
[被删除文件的父目录] 回收站目录 [; ...]
```

例如 `/data` 下的文件删除后移到 `/data/.recycle`，就写：

```
/data /data/.recycle
```

可以用分号配置多条，按目录分别指定。

> 只对界面上的删除操作生效。通过终端 `rm` 删除的文件不进回收站。

## 保护关键目录

防止误删 `/etc` 这类目录：

1. 打开 **设置 → 环境**
2. 找到「保护路径」
3. 填写不允许删除的目录，多个用逗号分隔

被保护的目录下，删除操作会被拒绝。分为「系统保护路径」和「用户保护路径」两种，前者对所有人生效，后者只对普通用户生效。

## Studio 模式编辑整个项目

要在服务器上改一个项目的多个文件：

1. 在文件列表里**右键文件夹**（不是文件）
2. 选择「Studio 打开」
3. 左侧出现文件树，点击文件在右侧编辑

比逐个双击文件方便，适合临时改一批配置或查看项目结构。

## 切换目录的三种方式

| 方式 | 说明 |
| --- | --- |
| 面包屑 | 点击路径中的任意一级直接跳转 |
| 面包屑输入 | 点击面包屑末尾可输入完整路径，回车跳转 |
| 相对路径 | 输入相对路径会基于当前目录解析，不能跳出根目录 |

## 搜索文件

当前支持**在当前目录内**按文件名搜索。输入关键词后即时过滤列表，不支持搜索文件内容。
