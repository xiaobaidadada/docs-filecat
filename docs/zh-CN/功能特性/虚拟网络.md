# 虚拟网络

给多台机器分配虚拟 IP，让它们看起来像一个局域网。适合没有公网 IP 的家庭或办公室环境。

## 使用步骤

**1. 准备一台有公网的机器当服务器**

在上面安装并启动 FileCat，打开 **设置 → 虚拟网络 → 服务器**，记下监听端口和 key。

**2. 其它机器配客户端**

在每台需要加入的机器上安装 FileCat：

1. 打开 **设置 → 虚拟网络 → 客户端**
2. 填服务器的公网 IP、端口、key
3. **自己指定一个虚拟 IP**（客户端 IP 由客户端自己设，服务器不分配）
4. 启动客户端

**3. 验证连通**

各机器之间就能用虚拟 IP 互相访问了。

> 在**同一台电脑**上测客户端连自己的服务器时，服务器地址填 `localhost` 即可。

## Windows 必须管理员运行

在 Windows 上创建虚拟网卡**需要管理员权限**。不是管理员身份启动 FileCat 的话，虚拟 IP 创建不出来。

## Windows 默认是「公共网络」

创建出来的虚拟网卡默认被识别为公共网络，**这时候 ping 不通**（但不影响正常通信）。

手动改成私有网络：

```bash
Set-NetConnectionProfile -InterfaceAlias "filecat" -NetworkCategory Private
```

验证是否改成功：

```bash
Get-NetConnectionProfile
```

看 `filecat` 那一条的 `NetworkCategory` 是不是 `Private`。

## 服务器主动访问客户端

服务器也可以**同时开启客户端**连接自己。

这样即使客户端在 NAT 后面，服务器也能主动向它发起请求 —— 解决了"只能客户端主动连服务器"的限制。

## 配合 TCP 代理访问内网其它主机

虚拟网络只解决「加入网络的机器之间互通」。

要访问某个客户端所在内网的**其它设备**（比如它旁边的打印机、NAS）：

1. 在那台客户端上配置 **TCP 代理**
2. 通过中转访问内网其它主机的 IP

## P2P 模式已移除

早期版本用 UDP 打洞实现 P2P 直连，但国内运营商对 UDP 限制较多（移动网络很多地区直接不可用），该功能已删除，不再维护。

现在所有流量都走服务器中转。选服务器时注意它的带宽和稳定性。
