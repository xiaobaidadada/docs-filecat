# AI 助手

接入大模型后，AI 不只是聊天，它能**直接读写文件、执行命令**帮你干活。

## 配置模型

1. 打开 **设置 → AI**
2. 填写 **API 地址**
   - OpenAI 官方：`https://api.openai.com/v1`
   - 国内中转 / one-api：填服务商给的地址
   - 本地 Ollama：`http://127.0.0.1:11434/v1`
3. 填写 **API Key**（本地 Ollama 随便填一个非空值即可）
4. 填写 **模型名称**，如 `gpt-4o`、`deepseek-chat`、`qwen2.5:7b`
5. 保存

只要兼容 OpenAI 格式的接口都能用。

## 开始对话

进入 **AI 对话** 页面，直接描述需求：

```
把这个目录下所有 .log 文件里包含 error 的行提取出来
```

AI 会调用工具去执行，每一步操作都会显示在对话里，你能看到它读了哪个文件、执行了什么命令。

## 控制 AI 的权限（重要）

AI 能操作服务器，所以**第一次用一定先限制权限**：

1. 打开 **设置 → AI → 工具权限**
2. 先只勾选**只读**相关工具（读取文件、查看目录、查询系统信息）
3. 跑几次，确认行为符合预期
4. 再逐步放开写文件、执行命令的权限

还可以限制 AI 只能访问指定目录，避免它碰到关键路径。

## 多会话管理

不同话题开不同会话，上下文互不干扰：

- 左侧列表可以新建、切换、删除会话
- 每个会话独立保存历史
- 会话标题可以改，方便区分

## 会话历史与中断

对话过程中随时可以中断：

- 点停止按钮，已生成的内容**会保留**在会话记录里
- 中断不会丢失之前的消息
- 下次打开这个会话可以接着聊

## 长期记忆

跨会话保留的重要信息，比如：

- 「这台机器的项目都在 /data/projects」
- 「改配置后要重启 nginx」

不用每次重复交代背景。可以在设置里查看和清理已保存的记忆。

## 配置钉钉机器人

在钉钉群里 @ 机器人就能用 AI 操作服务器。

1. 在钉钉开放平台创建企业内部应用，开启机器人能力
2. 拿到 `AppKey` 和 `AppSecret`
3. 打开 **设置 → AI → 机器人 → 钉钉**
4. 填入 AppKey、AppSecret
5. 保存后到钉钉群里添加这个机器人

之后在群里 @ 它提问即可。

## 配置飞书机器人

1. 飞书开放平台创建企业自建应用，开启机器人
2. 拿到 `App ID` 和 `App Secret`
3. 在 **设置 → AI → 机器人 → 飞书** 填入
4. 配置事件订阅回调地址（指向 FileCat 的对应接口）
5. 在群里添加机器人

## 配置 QQ 机器人

QQ 机器人需要通过官方 QQ 开放平台申请，拿到 AppID、Token、Secret 后填入 **设置 → AI → 机器人 → QQ**。

> QQ 机器人有较严格的审核流程，个人开发者也需实名。

## AI 回答不准？

- **模型能力不足** —— 换更大的模型，小模型做工具调用容易出错
- **上下文太长** —— 开新会话，避免历史干扰
- **权限不足** —— 检查工具权限是否限制了它需要的操作
- **接口不通** —— 先在设置里点测试连接，确认地址和 Key 正确
