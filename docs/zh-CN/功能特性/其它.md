# 其它功能

这里收录功能明确但用法简单的能力，各用一句话说明，暂不展开教程。

## 服务器管理

| 功能 | 说明 |
| --- | --- |
| **系统监控** | 实时查看 CPU、内存、磁盘、网络占用，数据采集用 C++ 实现，几乎不占用资源 |
| **进程管理** | 查看服务器上所有进程，支持结束进程；性能优于同类面板 |
| **Docker 管理** | 查看容器列表、日志，启停容器 |
| **systemd 管理** | 管理 systemctl 服务，启停、查看状态与日志，主流面板少有提供 |
| **磁盘管理** | 查看磁盘挂载情况，配置挂载项 |

## 安全与网络

| 功能 | 说明 |
| --- | --- |
| **用户与权限** | 多用户，可控制每个账号能看到的目录范围和可执行的操作 |
| **操作日志** | 记录文件操作、登录、命令执行等行为 |
| **DDNS** | 动态域名解析，支持阿里云、腾讯云、Cloudflare、DNSPod、GoDaddy、Namecheap、NameSilo、Vercel、DynDNS、TokenDNS、HTTP DDNS 等十余家服务商 |
| **证书申请** | 申请和续期 SSL 证书，用于 HTTPS 访问 |
| **防火墙** | 管理服务器防火墙规则 |
| **端口扫描** | 扫描指定主机的开放端口 |

## 远程访问

| 功能 | 说明 |
| --- | --- |
| **SSH 管理** | 保存多个远程 Linux 服务器的账号密码，一键登录后可像本地一样管理其文件、执行终端命令。几乎具备本地文件操作的体验，支持代码编辑但不支持文件预览；终端使用远程服务器自带终端，而非 pty-shell |
| **RDP 桌面** | 在浏览器中远程控制 Windows 桌面 |
| **浏览器代理** | 提供一个 HTTP 代理端口，直接在浏览器打开内网 Web 服务（如路由器后台）。需要占用一个额外端口 |
| **HTTP 代理** | 内置小型 Postman，支持表单上传文件与后台下载远程资源，可指定下载目录并直接保存到服务器 |
| **网址收藏夹** | 保存常访问的 Web 地址，支持多级目录分类 |
| **快捷命令** | 保存常用命令，一键执行 |
| **RTSP 播放器** | 需额外安装 ffmpeg，填入 rtsp 地址即可在线播放监控画面 |
| **网络唤醒** | 填入目标主机的 MAC 地址即可发送 WOL 唤醒包，对方插上网线即可被唤醒 |

## 内容与媒体

| 功能 | 说明 |
| --- | --- |
| **视频播放** | 在线播放视频，支持常见格式 |
| **视频转码** | 借助系统安装的 ffmpeg 转换视频格式（ffmpeg 体积大，需自行安装） |
| **图片预览** | 网格预览图片，网络较差时可右键关闭预览以提升速度 |
| **文本对比** | 对比两个文件的差异 |

## 自动化

| 功能 | 说明 |
| --- | --- |
| **Workflow 工作流** | 内嵌工作流引擎，语法参考 GitHub Actions，可替代 Jenkins 做构建 |
| **计划任务** | 按 Cron 表达式定时执行命令或任务 |
| **HTTP 代理下载** | 后台下载远程 HTTP 资源，不占用浏览器 |
| **静态资源代理** | 把任意目录作为静态站点对外提供，支持自定义登录 |
| **短信与邮件通知** | 任务执行结果、异常事件的通知渠道 |

## 界面与体验

| 功能 | 说明 |
| --- | --- |
| **多语言** | 界面支持中文与英文切换 |
| **深色主题** | 跟随系统或手动切换 |
