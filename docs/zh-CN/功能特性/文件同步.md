# 文件同步

在两台 FileCat 之间同步目录，基于 TCP 直连。

## 同步是单向的

从**同步端**流向**接收端**。要双向同步就配两条，方向相反。

## 第一步：接收端开启服务

1. 在**接收文件的那台机器**上打开 **设置 → 同步 → 接收端**
2. 设置**监听端口**，例如 `9100`
3. 设置**认证 token**
4. 保存并启动
5. **在防火墙放行这个端口**

## 第二步：同步端配置连接

1. 在**提供文件的那台机器**上打开 **设置 → 同步 → 同步端**
2. 填写接收端的 **IP 和端口**
3. 填写 **token**（必须和接收端一致）
4. 保存

## 第三步：添加同步任务

在同步端新增一条任务：

| 字段 | 填什么 |
| --- | --- |
| 本地目录 | 要同步出去的源目录，如 `/data/www` |
| 远端目录 | 接收端的目标目录，如 `/backup/www` |

保存后启动任务。

## 首次同步注意

第一次会把源目录**全部内容**传一遍。目录大、跨公网时很慢，建议：

1. 先在局域网内完成首次同步
2. 再把机器搬到目标位置 / 切到公网
3. 之后只传变化的部分

## 常见问题

**连不上接收端**
先 `telnet 接收端IP 9100` 测端口，不通就是防火墙或端口没启动。

**token 报错**
两端 token 必须完全一致，注意有没有多余空格。

**同步了但文件不全**
检查源目录里的文件是否被 FileCat 进程用户读取权限覆盖；权限不足的文件会被跳过。
